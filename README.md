# Поле маркетинговых чудес

Браузерная игра для трёх команд. Без внешних зависимостей; подходит для GitHub Pages.

## Запуск

Из папки `game`:

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Можно также открыть `index.html` напрямую в браузере.

Правила и состав раундов описаны в `RULES.md` и `app.js`.

## Публикация

Сайт статический. Для GitHub Pages выберите ветку `main` и папку `/ (root)` в настройках Pages. Файл `.nojekyll` отключает обработку Jekyll.

## Готовый компонент

Барабан использует локальную копию [spin-wheel 5.0.2](https://github.com/CrazyTim/spin-wheel) (MIT). Файл и текст лицензии находятся в `vendor/`. Сетевые запросы для работы игры не требуются. Шрифт Manrope также хранится локально (`vendor/`, лицензия OFL). Игра полностью работает без интернета.

## Стиль и материалы

Игра оформлена как неофициальный учебный оммаж телевизионной игре: заставка, яркие студийные цвета, светящееся табло, портрет ведущего, тихая фоновая мелодия и игровые звуки. Для фоновой музыки и всех звуков есть отдельные выключатели. Источники и условия использования материалов перечислены в `assets/CREDITS.md`.
